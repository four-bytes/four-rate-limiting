# Security Policy

## Supported Versions

The latest released minor version receives security fixes.

| Version | Supported |
|---------|-----------|
| 1.3.x   | Yes       |
| < 1.3   | No        |

## Reporting a Vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately through GitHub Security Advisories:

https://github.com/four-bytes/four-rate-limiting/security/advisories/new

Include as much detail as possible:

- affected version(s)
- steps to reproduce
- impact assessment
- any suggested fix

We will acknowledge the report as soon as possible, investigate it, and keep you
informed about the progress. Please give us reasonable time to release a fix
before any public disclosure.
